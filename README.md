# Student Result Processor

An OOP mini project for OOP1 that captures student marks,
calculates averages and classifies results as Distinction, Pass or Fail.

## Files
- student.py: the Student class (attributes and methods)
- main.py: input, validation and the formatted report

## How to run
py main.py

## OOP concepts used
Classes and objects, constructor (_init_), methods, class attributes,
